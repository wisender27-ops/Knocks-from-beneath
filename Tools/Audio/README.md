# Звук A-01: сборка клипов

Скрипты, которыми собраны `Assets/Audio/Game/**` и выровнены старые клипы (Python 3 + numpy/scipy + ffmpeg).

- `audiolib.py` — загрузка/сохранение через ffmpeg, нормализация по громкости (самое громкое окно 400 мс), лимитер, петли, фильтры.
- `synth.py` — собственные синтезированные слои: дроны, тон комнаты, гул ламп, сердцебиение, звон в ушах, низкие удары.
- `build_a01.py` — сборка всех клипов A-01. Исходники (Kenney, OpenGameArt, Freesound — все CC0) скачиваются в папку `dl/`
  рядом с `tools/`; ссылки и авторы — в `Assets/ThirdPartyCredits.md`. Запуск: `python build_a01.py [ui|foley|world|ambience|music|horror|events|agent]`,
  результат — `build/Audio/Game`, оттуда копировать в `Assets/Audio/Game` (имена файлов те же — GUID в `.meta` сохраняются).
- `renorm_inplace.py` — выравнивание громкости старых клипов на месте (тот же путь и формат → тот же GUID); оригиналы — в `backup/`.

Уровни (самое громкое окно 400 мс, dBFS): UI −22…−34, шаги −19…−23, предметы −19, двери −17…−21, стук/удары −14…−16,
скримеры −12…−13; фоны по RMS: улица −27…−29, дождь −25, тон комнаты −44, дроны −23…−25. Баланс событий — громкостью источника
в коде и шинами `MainMixer`.
- `build_b07_voice.py` — B-07: голос монстра «Don't move» (Piper TTS → тон/форманты вниз, октава с кольцевой модуляцией, шёпот,
  насыщение, обратный ревёрб). Инструкция — в шапке скрипта.
