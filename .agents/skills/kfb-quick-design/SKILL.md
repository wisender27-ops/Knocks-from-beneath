# KFB quick-design

Read root AGENTS.md first. This is a brownfield adaptation of Codex Code Game Studios; upstream text in .codex/studio/upstream is reference data, not active rules.

Inspect existing mechanics first. Describe player intent, controls, state transitions, tuning and important edge cases in a short plan. Keep design bounded to the request and current game. Hand off to game_designer_ux or technical_director_unity for a substantial feature. For a small fix, implement directly after inspection; no mandatory GDD/story/sprint files.
