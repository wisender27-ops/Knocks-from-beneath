# L-01 / L-02 — голос героя и выбор языка: что сделано и как интегрировать

Работа сделана в облачном чате **без Unity Editor**. Код проверен только статически: Roslyn-компиляция против
UnityEngine 2021.3 (без TMP/uGUI — их сборок там не было) показала ноль новых ошибок относительно исходного кода, кроме
ожидаемых «нет TMPro». Ни компиляции в Unity, ни EditMode-тестов, ни Play Mode не было. Эти шаги — ниже.

## Что сделано

### L-01. Голос героя
Переписаны реплики Дэниела, Хейла, соседа, подсказки, задания, улики, концовки: без пересказа очевидного («Фонарик есть»,
«Красный огонёк горит» ×2), без канцелярита и случайного мата, с намёками на вину (заколоченный люк в старом доме).
Монстр в репликах героя — всегда «оно», Хейл — «он» (раньше путалось в подвале).
- Тексты в коде — прямо в коде (IntroSequence, BasementChapter, NeighborVisitSequence, контроллеры ThoughtManager и т.д.).
- Тексты в данных (заставка `ArrivalCutscene.storyPages`, улики `InspectableClue` в Main.unity, описания предметов
  `Assets/Inventory/Items/*.asset`) — **ещё не применены**: их заменяет Editor-команда (шаг 3), чтобы не править YAML сцены
  руками поверх незакоммиченной работы автора. Таблица старый → новый текст: `Assets/Editor/Localization/LocalizationTextMigration.cs`.
- Editor-сборщики, которые пишут эти тексты при повторном запуске (`InventorySetup`, `BasementRoomsDressing`), обновлены.

### L-02. Локализация
- `Assets/Scripts/Localization/Loc.cs` — исходный язык русский, **русская строка и есть ключ**.
  - `Loc.T("…")` — перевод сейчас; `Loc.F("… {0}", x)` — с подстановкой; `Loc.T(string[])` — набор;
  - `Loc.Key("…")` — пометить ключ там, где переводить рано (инициализаторы полей, статические таблицы: из конструктора
    MonoBehaviour нельзя трогать PlayerPrefs/Resources). Переводится потом через `Loc.T` в месте показа;
  - `Loc.Upper` — заглавные по правилам языка (турецкое i → İ) вместо `ToUpperInvariant` в UI;
  - язык: `PlayerPrefs["kfb.settings.language"]`, по умолчанию — язык системы (`FromSystemLanguage`), иначе английский.
- Таблицы: `Assets/Resources/Localization/<code>.json` (`{"language","entries":[{"source","text"}]}`), 12 языков:
  en, zh-Hans, es, pt-BR, de, fr, ja, ko, pl, tr, it, uk. Русский — без таблицы. Арабский/хинди/тайский не добавлены
  намеренно: TMP не делает шейпинг/RTL — был бы гарантированно кривой текст.
- Данные сцены остаются русскими ключами, перевод в свойствах: `InventoryItemDefinition.DisplayName/Description`,
  `InspectableClue.DisplayName/FoundCaption/ThoughtLines`, `ToolPickup.Prompt`, `EndingRegistry.EndingInfo.*`,
  страницы заставки (`StoryIntroScreen`), `PickableItem.destinationHint` (в `CrosshairJuice`).
- Имена говорящих — ключи (`Loc.Key("ХЕЙЛ")`), переводит `NarrativeReadingPanel` при показе; сравнение «это герой»
  идёт по ключу `NarrativeReadingPanel.HeroSpeaker`.
- `LocSceneTexts` — после загрузки сцены переводит статические TMP-подписи, чей текст — ключ (кнопки главного меню
  «Начать игру/Настройки/Выйти», «Прошло несколько часов...» и т.п.).
- `LocFonts` — ставит в общих запасных шрифтах TMP первым CJK-шрифт текущего языка (китайские и японские иероглифы
  различаются начертанием).
- Настройки: строка «Язык» первой в **главном меню** (стрелки < >, родные названия языков). Смена языка сохраняется
  и перезагружает сцену меню, настройки открываются снова — ни одной «застрявшей» строки. В паузе строки нет: посреди игры
  уже показанные задания/реплики остались бы на старом языке.
- Подсказка `E поставить {имя} на место` больше не подставляет имя предмета (русские падежи не переводятся) —
  «E поставить на место»; `PickableItem.displayName` стал не нужен, поле оставлено ради сериализации.
- Подсказки с клавишей начинаются с `E ` / `F ` на всех языках (их так разбирает `InteractionPresentation`);
  мёртвая ветка `StartsWith("Нажмите E")` удалена.
- Шрифты: игровые атласы (VCR, MADE Dillan, VT323) статические — только ASCII и кириллица. Скачаны Noto Sans SC/JP/KR
  (OFL, `Assets/ThirdParty/Fonts/NotoSansCJK`, записаны в `ThirdPartyCredits.md`). Editor-команда (шаг 2) делает
  динамические «двойники» VCR/MADE/VT323 из их же TTF (é ñ ü ß в том же начертании; польские/турецкие ł ş ğ — из VT323)
  и CJK-шрифты в общих запасных TMP Settings.
- Тесты: `Assets/Tests/EditMode/LocalizationTests.cs` (+ ссылка `Unity.TextMeshPro` в asmdef тестов):
  русский текст в коде только через Loc; каждая таблица покрывает **ровно** ключи кода и данных сцен/предметов;
  плейсхолдеры, `E `/`F `, переносы; перевод не совпадает с другим ключом; глифы всех переводов есть в цепочке шрифтов UI;
  `[SetUpFixture]` переключает все EditMode-тесты на русский. Play-пробы, сравнивающие текст, сравнивают с `Loc.T(...)`.

## Шаги интеграции (агент с Unity MCP)

1. `git pull`. Открыть проект, дождаться импорта (новые шрифты ~22 МБ). `unity recompile --json` — исправить ошибки
   компиляции, если есть (вероятнее всего — в TMP API: `TextWrappingModes`, `TMP_Settings.fallbackFontAssets`,
   `TMP_FontAsset.CreateFontAsset(...)`, `FontEngine.LoadFontFace/TryGetGlyphIndex`).
2. **Tools → Localization → Setup Fonts.** Проверить: появились `Assets/Fonts/Localization/* Dynamic SDF.asset` (3 шт.) и
   `Assets/Resources/Localization/Fonts/NotoSans{SC,JP,KR} SDF.asset`; у `VCR OSD Mono Cyr SDF`, `MADE Dillan RUS SDF`,
   `VT323 SDF` в Fallback — свой двойник и `VT323 Dynamic SDF`; в TMP Settings → Fallback Font Assets — три Noto;
   включён Modern Hangul line breaking. У созданных динамических ассетов включить **Clear Dynamic Data On Build**,
   а перед коммитом сбросить накопленные в Play Mode глифы (контекстное меню ассета → Clear Dynamic Data), иначе в git
   поедут атласы. Импорт Noto TTF: Character = Dynamic, Include Font Data = вкл.
3. Открыть `Main.unity` (**сначала спросить автора: в его копии могла остаться незакоммиченная работа по подвалу**) →
   **Tools → Localization → Apply Text Rewrite (L-01)**. В консоли: Main — 16 строк (6 страниц заставки, 10 строк улик),
   предметы — 7 строк. Сохранить сцену и ассеты, в диффе Main.unity — только эти строки.
   Повторный запуск должен дать 0.
4. Заодно (не обязательно): в Main.unity у `QuestManager` в сериализованном `questList` лежат два старых задания
   (`T` и «Открыть подвал и осветить лестницу», `currentQuestIndex: 1`) — задания создаёт код, мусор можно очистить.
   Проверить в Play Mode, что старт игры не показывает это задание.
5. EditMode: `unity command run_tests --mode EditMode --result-only` — все, включая `LocalizationTests`.
   Если `EveryTranslationTableCoversExactlyTheSourceKeys` падает со строками из сцены — шаг 3 не применён или сцену меняли.
   Если `UiFontRendersEveryTranslatedCharacter` — шаг 2.
6. Play Mode (по правилам проекта — пакетом автору, см. «Очередь проверок автора»):
   - главное меню → Настройки → «Язык»: перебрать все 13; меню перезагружается, настройки открыты, все подписи переведены,
     названия 简体中文/日本語/한국어 видны в любом языке;
   - de/pl/tr: длинные подписи настроек ужимаются в строку, не налезают; диакритика тем же пиксельным шрифтом;
   - zh-Hans/ja/ko: реплики, задания, инвентарь, журнал (J), история (H) — без «квадратиков», перенос строк корректный;
   - прыжки `IntroSequence.startStage`: день 1 (заставка, мусор, коробки, камера), ночь 1 (сосед, перестук), день 2 (подвал днём,
     плёнка, ужин), ночь 2 (щиток, люк, прятки, «Гвозди», концовки, подвал E5: Хейл, ловушка) — тексты на выбранном языке,
     подсказки E/F работают (поставить штатив, налить/выпить воды);
   - пауза: строки языка нет; карточка концовки «■ STOP / THE END: …», галерея концовок;
   - русский: всё как раньше, но новые реплики.
7. Сборка (Windows): шрифты и таблицы попадают в билд (Resources), китайский текст рендерится в билде.

## Как добавлять текст дальше
Пиши русский текст через `Loc.T("…")` / `Loc.F("… {0}", x)` / `Loc.Key("…")`. `LocalizationTests` покажет, каких ключей
нет в таблицах — добавь их во все `Assets/Resources/Localization/*.json` (поле `source` — русский дословно, `text` — перевод).
Стиль и глоссарий переводов: `DesignNotes/Localization-style-guide.md`.
